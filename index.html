Security & Permissions

Transparent on-device processing.

Smart Island requires specific Android system permissions to draw overlays and process notifications locally with zero data transmission.

100% On-Device & Private

Built without INTERNET permission.

Smart Island does not request the Android INTERNET permission in its manifest, contains zero analytics or crash reporting SDKs, and processes all notification metadata locally on your device.

Information Processed Locally:

  • App name, package ID, title & notification text
  • Album artwork, track playback state & seek progress
  • Incoming call categories & active hotspot device counts
  • DataStore Preferences for user customization options
SYSTEM_ALERT_WINDOW Overlay

Floating Overlay Window

Draws the animated pill overlay above other apps using Android WindowManager APIs.

BIND_NOTIFICATION_LISTENER Notifications

Notification Listener Access

Reads active notification title, text, artwork, and call/media states to create glanceable cards.

BIND_ACCESSIBILITY_SERVICE System Service

Accessibility Overlay Service

Maintains persistent island rendering across all app transitions and lock screen states.

FOREGROUND_SERVICE_SPECIAL_USE Foreground Engine

Special Use Foreground Service

Prevents Android OS from killing the overlay service during low memory conditions.

REQUEST_IGNORE_BATTERY_OPTIMIZATIONS Battery Whitelist

No Battery Restrictions

Ensures background OEM battery managers (Xiaomi, Samsung, Oppo) do not kill island processes.

PACKAGE_USAGE_STATS Auto-Hide

Usage Access

Detects full-screen landscape apps to auto-hide the island during gaming and video playback.

moe.shizuku.manager.permission.API_V23 Shizuku 1-Tap

Shizuku 1-Tap Permission Manager

Allows 1-tap automated setup for Android 13+ devices without requiring ADB terminal commands.

RECEIVE_BOOT_COMPLETED Autostart

Autostart Receiver

Restores your overlay preference and service automatically when your Android device reboots.
